How to use this test

  1. Stay on the connection you want to compare

    Use the Wi-Fi or network you want to check and pause large transfers if practical.

  2. Measure once

    Choose Measure speed and let the download and upload complete.

  3. Compare carefully

    Run a second sample if needed; short tests can vary with server load and network activity.

What we check

The page downloads a 2 MB file from this site, then posts a matching 2 MB sample back to its measurement endpoint.

It divides the transferred bytes by browser timing for a short result in Mbps.

What this test can’t tell you

It cannot see Wi-Fi signal strength, identify the radio band, measure every destination, or separate your router, ISP and server limits.

Something not working?

The upload is unavailable

A static host needs a same-site upload endpoint for the second half of this check. The page will say so instead of inventing a result.

The result changes

That is normal for a small transfer. Try again after pausing downloads, streams and cloud backups.

Common questions

Does it prove my Wi-Fi is the problem?

No. It measures the path between this browser and this website, not Wi-Fi hardware alone.

Why is this different from another speed test?

Each service uses different files, locations, durations and server capacity.
