How to use this test

  1. Check the preview

    Look for the one-page document in the embedded viewer.

  2. Download the file

    Use Download PDF and open the saved file in your usual PDF reader.

  3. Compare the results

    A browser may handle embedded previews differently from downloaded files.

What we check

The page creates a one-page print-quality PDF locally and exposes it through a temporary browser object URL.

The document uses colour blocks, mix blocks, fine line weights, type sizes and registration targets similar to the print test page.

What this test can’t tell you

It does not test every PDF feature, large file, font, signature, form, annotation or external PDF reader.

Something not working?

The preview is blank

Your browser may download PDFs instead of embedding them. Use the download link and open the file separately.

The download does not start

Check browser download permissions or try the link again after allowing downloads.

Common questions

Is the PDF uploaded?

No. It is generated in the browser and kept in local memory.

What does the PDF contain?

A one-page Test Institute print-quality check with colour, line, type and alignment samples.
