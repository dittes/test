How to use this test

  1. Read the word

    The first word is always new. Look at its spelling; similar words are still different words.

  2. Choose Seen or New

    Seen means the word appeared at any earlier point in this run, even if you answered incorrectly then. Use the buttons or the S and N keys.

  3. Review the run

    Each correct decision earns one point. Three mistakes end the game, or you finish after 60 decisions. There is no time limit.

What we check

The game draws from a bundled list of everyday English words. Once at least one word has appeared, each next draw has a 40% chance of repeating an earlier word; otherwise it introduces an unused word.

Your score counts correct decisions, not the number of unique words remembered. Reset clears the entire seen-word history. A word from a previous run is new again.

What this test can’t tell you

This is a practice game, not an IQ test, health screening or clinical assessment. The score describes this run, not your overall ability. There are no population rankings.

Something not working?

The same word came back immediately

Immediate repeats are allowed. It is Seen because it appeared earlier in the current run.

The keyboard shortcut did not register

Use S for Seen or N for New when focus is inside the game. Holding a key does not submit repeated answers.

Common questions

Do I need to know what the words mean?

You only need to recognize their spelling, but familiarity with English can make the task easier. This is not a language-neutral comparison.

Does an incorrect answer change the history?

The displayed word still becomes part of the history. If it appears again, the correct answer is Seen.

Are the words sent to a server?

No. The word list and run history stay in your browser. There are no accounts or saved rankings.
