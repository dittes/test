How to use this test

  1. Clean the screen first

    Wipe away dust and fingerprints so a surface mark is not mistaken for a pixel issue.

  2. Open a colour field

    Show each solid field in full screen and look slowly across the panel from a normal viewing distance.

  3. Compare the same spot

    If a dot stands out, switch between fields and note whether it stays in the same physical location.

  4. Exit comfortably

    Leave full screen with the provided control or Escape. Stop if bright fields are uncomfortable for you.

What we check

The page displays solid colour fields and simple contrast patterns. Different backgrounds can make a dark, bright, or permanently coloured point easier for a person to notice than ordinary desktop content.

You inspect the display with your own eyes. If the same point remains visible across several fields, it is worth comparing with another application or device input before seeking service.

The page reports the current browser viewport size, selected pattern and your selected observation. Those values describe this browser session; they do not count pixels or establish the panel’s native characteristics.

What this test can’t tell you

A web page cannot programmatically see your panel, detect a dead or stuck pixel, certify brightness, verify HDR, or calibrate colour accuracy.

This is not an eyesight, colour-vision, flicker, refresh-rate, or medical test. Avoid flashing patterns; page animation timing is not a monitor refresh-rate measurement.

Something not working?

I see a spot on every field

Clean the panel, then check whether the spot stays fixed when you open another app or change the input. Dust, damage and panel behaviour can look similar.

The colours look different than expected

Night mode, colour profiles, HDR, ambient-light adjustment and browser rendering can change appearance. This page cannot calibrate or correct them.

Full screen will not open

Use the browser’s full-screen permission if prompted, or inspect the fields in the normal page view. Some embedded or managed browsers restrict full screen.

The display flickers or feels uncomfortable

Leave the test immediately and reduce brightness. Do not use this page to investigate a health symptom; check device settings or seek appropriate support.

Common questions

What is the difference between a dead and a stuck pixel?

A dead pixel may appear dark, while a stuck pixel may remain bright or coloured. This page cannot determine which condition you have; it only helps you inspect a fixed spot.

Can the test repair a stuck pixel?

No. It provides static inspection fields and does not claim to repair panel hardware.

Can it test my monitor’s refresh rate?

No. Animation-frame timing reflects the page, browser and system scheduling, not a direct measurement of monitor refresh hardware.

Why do the fields not fill every screen?

Browser chrome, device cut-outs, zoom and full-screen permissions can affect the visible area. Use the full-screen control where available.
