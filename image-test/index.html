How to use this test

  1. Inspect the pattern

    Look at the lines, gradient and colour blocks at a comfortable zoom.

  2. Download the PNG

    Use Download image to save the locally generated file.

  3. Compare elsewhere

    Open the saved image in another viewer if a difference matters.

What we check

The page draws the pattern on a canvas and creates the PNG download in the browser.

This can show how the browser renders this particular pattern and handles the local download.

What this test can’t tell you

It is not a display calibration, colour-profile, camera, printer or image-compression test.

Something not working?

The image looks different elsewhere

Different apps can apply colour management, zoom or display settings differently.

The download is blocked

Allow downloads for this site, then try the button again.

Common questions

Is an image uploaded?

No. The image is generated in the browser.

Can it calibrate my display?

No. It is only a practical visual comparison pattern.
