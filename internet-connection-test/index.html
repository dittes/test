How to use this test

  1. Run the check

    Choose Check connection to refresh the displayed browser information.

  2. Read the status

    Note whether the browser reports online or offline.

  3. Compare the problem

    If a service still fails, try another site or application before changing settings.

What we check

The page reads navigator.onLine and, where a browser provides it, a general connection estimate.

Connection estimates are optional browser features and may be absent or imprecise.

What this test can’t tell you

It does not perform a speed test, measure latency, inspect Wi-Fi signal, or confirm that a particular service is available.

Something not working?

The estimate is unavailable

Many browsers do not expose connection information. The online/offline status can still appear.

It says online but a site fails

Online status does not prove that every destination is reachable. Compare another site or app.

Common questions

Is this a speed test?

No. It does not download a test file or report Mbps.

Why is the connection type missing?

Connection information is not supported consistently across browsers.
