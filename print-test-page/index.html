How to use this test

  1. Open the print dialog

    Choose Open print dialog and select your printer or Save as PDF.

  2. Inspect preview

    Look for clipped content, unexpected margins and missing colour.

  3. Print one page

    Use a single sheet before changing settings or printing a larger document.

What we check

The page uses the browser print dialog and print-specific CSS to present a clean one-page layout.

Your selected printer, driver, paper and browser determine the final output.

What this test can’t tell you

It does not inspect ink levels, paper feed, printer hardware, driver condition or colour calibration.

Something not working?

The page is clipped

Check paper size, orientation, scale and browser margin settings in the preview.

Colour does not print

Enable background graphics if needed and check the printer’s colour settings.

Common questions

Can I save this as a PDF?

Yes, if your browser or operating system offers Save as PDF in its print dialog.

Does the page send a print job itself?

No. You choose the printer and confirm the job in your browser dialog.
