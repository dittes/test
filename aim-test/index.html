How to use this test

  1. Choose your input

    Use a mouse, trackpad or touch screen. Keep the same input method and browser size when comparing runs.

  2. Hit each target

    Choose Start test. Timing begins when the first target appears. Click or tap its square outline; the whole marked square counts as a hit.

  3. Read both results

    After 20 hits, compare total time and accuracy. A fast run with many misses tells a different story from a clean run.

What we check

The target is a 48-pixel square placed inside the test area. Each hit moves it to a new position at least 60 pixels from its last position. Timing includes your response to the first target.

Average time per target is total time divided by 20, including time spent on misses. Accuracy is hits divided by all primary clicks or taps inside the arena. Clicks on controls outside it are not counted.

Keyboard activation is supported as an accessibility practice mode and is labeled separately; it does not measure pointer aim. Resizing or leaving the page cancels the run.

What this test can’t tell you

This is a practice game, not an IQ test, health screening or clinical assessment. The score describes this run, not your overall ability. There are no population rankings.

Something not working?

Touch feels different from a mouse

It is a different movement task. Compare touch runs with touch runs, not with mouse or trackpad scores.

The run stopped when I rotated my phone

Rotation changes the target area. Start again after choosing the orientation you want to use.

Common questions

Is this a gaming aim trainer?

It is a small, static-target exercise. It does not reproduce recoil, moving opponents, field of view or sensitivity inside a game.

Why include accuracy?

Time alone can hide careless clicking. Accuracy counts only clicks and taps inside the arena, making the trade-off visible.

Is lower always better?

A lower time means a faster run on this setup. Keep target size, viewport and input method consistent before treating a difference as progress.
