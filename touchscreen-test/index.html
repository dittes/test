How to use this test

  1. Tap the surface

    Tap once in several areas. The page marks the last point it received.

  2. Move slowly

    Keep a finger or stylus on the surface and move it across the area to check for a continuous response.

  3. Try the affected area

    If part of a screen is in doubt, use that part of the visible test surface and compare with a nearby area.

  4. Compare before deciding

    Try another app or restart the device before treating a missing event as a hardware fault.

What we check

The page listens for pointer events inside its own test surface. It can show the most recent position, the pointer type reported by the browser, and whether a press or release arrived.

A received event means this browser received that interaction in this area at that moment. It does not reveal the condition of the touch panel, screen protector, digitizer, firmware or device calibration.

The page does not record input outside the marked surface and does not save your touches. Reset clears the current local observation.

What this test can’t tell you

This is not a multi-touch, pressure, palm-rejection, latency or touch-panel calibration test.

Browser gestures, accessibility features, an overlay, a damaged screen protector or the operating system can change what reaches the page.

Something not working?

Nothing happens when I tap

Make sure the page is fully loaded and tap inside the marked surface. If a browser or app overlay is covering it, close that first.

The wrong point is marked

Check screen zoom, rotation and any display scaling setting. A browser can report a local position even when the device’s visual calibration feels wrong.

One area does not respond

Clean and dry the display, remove a case or screen protector if appropriate, then compare in another app. This page cannot diagnose the cause.

I am using a mouse

A mouse can still activate the surface, but it is reported as a mouse pointer. Use a finger or compatible stylus to check touch input specifically.

Common questions

Does this test support a stylus?

It can show the pointer type that the browser reports. Stylus features such as pressure and tilt are not assessed by this basic check.

Can it find dead areas on my touchscreen?

It can show whether a pointer event arrived in the part of the test surface you used. Confirm any suspected area in another app before drawing conclusions.

Does it save my touches?

No. The page keeps only the current local result while it is open and does not upload touch data.

Can it test several fingers at once?

No. This page is designed for a simple single-pointer check rather than a multi-touch capability test.
