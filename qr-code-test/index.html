How to use this test

  1. Open on one device

    Keep this page visible on the screen you want to test.

  2. Scan with another device

    Use a phone camera or QR scanner and point it at the code.

  3. Confirm the result

    The code should open this QR code test page.

What we check

The QR image is bundled with this page and encodes the URL of this test.

A scan confirms that the scanner recognised this particular code under the current lighting, focus and distance.

What this test can’t tell you

It does not test every QR size, damaged code, camera sensor, autofocus system or scanning application.

Something not working?

The camera will not recognise it

Increase screen brightness, reduce glare, clean the camera lens and try a little farther away.

The code opens nothing

Check that the scanner is allowed to open links and that the scanning device has a connection.

Common questions

Does the QR code contact another service?

No. The QR image is bundled with the page.
