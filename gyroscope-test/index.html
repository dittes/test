How to use this test

  1. Start the sensor

    Allow motion access if your browser asks.

  2. Rotate carefully

    Tilt and turn the device around one axis at a time.

  3. Watch the values

    Look for values that respond to each movement.

What we check

The page observes only the browser API or touch events available during this session.

Values and availability depend on the device, operating system, browser and permissions.

What this test can’t tell you

Orientation events can be filtered, unavailable or permission-gated. They are not a calibrated motion measurement.

Something not working?

The test is unavailable

Open the page on the phone or tablet you want to check, then use a current browser and allow a sensor permission only if prompted.

The value does not change

Move the device deliberately or try another browser. A web page cannot enable a sensor that the browser does not expose.

Common questions

Does this diagnose my device?

No. It shows what the browser received in this session.

Is any sensor data uploaded?

No. The displayed values stay in this browser.
