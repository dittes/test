How to use this test

  1. Watch first

    Start with one tile. Each cue lasts 600 milliseconds, with a short gap so repeated tiles remain distinguishable.

  2. Repeat the order

    When the page says Your turn, tap the same tiles in the same order. You can also use keys 1–9, arranged left to right across the grid.

  3. Build the sequence

    A correct round adds one tile. The first wrong selection ends the run; your score is the longest sequence you completed, not the round you reached.

What we check

The game keeps the previous pattern and appends one randomly chosen tile each round. A tile can occur more than once, including twice in a row.

There is no response deadline. Watching and recalling are separate phases, so tapping during playback does not count. Switching away cancels the run rather than letting a hidden timer play the pattern.

What this test can’t tell you

This is a practice game, not an IQ test, health screening or clinical assessment. The score describes this run, not your overall ability. There are no population rankings.

Something not working?

I cannot select a tile

Wait until playback finishes and Your turn appears. During playback the grid is intentionally locked.

The same tile appears twice

That is part of the pattern. The brief unlit gap separates the two cues; select that tile twice when answering.

Common questions

Is this the same as visual memory?

Not quite. This sequence game asks you to remember order. A visual memory game usually asks where several items appeared, without an ordered series.

Can I use a keyboard?

Yes. Keys 1–9 match the printed tile labels. Tab and Enter also work. This is the top-row number arrangement, not the reversed layout of a numeric keypad.

What is a good sequence memory score?

Use your own runs under similar conditions as a reference. We do not have a representative sample that would justify an average or percentile.
