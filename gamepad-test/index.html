How to use this test

  1. Connect the controller

    Plug in or pair the controller using your operating system, then return to this page.

  2. Press a button

    Choose Check for controller and press any button if the browser has not listed the device yet.

  3. Move a stick or trigger

    Use one control at a time and watch the browser-reported values change.

  4. Compare elsewhere

    If a control is absent here, compare it in a game or system controller settings before deciding the hardware has failed.

What we check

Where supported, the browser exposes connected controllers through the Gamepad API. The page reads the active controller’s reported buttons and axes during the current session.

A changing value shows that this browser received a change from that controller. Button names, layouts, dead zones and driver handling vary by device and browser.

The page does not install drivers, change mappings or send input to a game. It only displays values that the browser exposes locally.

What this test can’t tell you

This is not a vibration, wireless-range, battery, dead-zone, latency or controller-calibration test.

Some browsers do not support the Gamepad API fully, and an operating system or game launcher may hold or transform controller input before it reaches the browser.

Something not working?

No controller appears

Reconnect or re-pair the controller, then press a button while this page is open. Check whether the operating system sees it first.

The wrong controller appears

Disconnect other controllers where practical and reload the page. Browsers may list devices in a different order from a game.

A stick does not return to zero

Small reported values can reflect a controller’s current output or its configured dead zone. Compare the same control in system settings or another game.

Buttons work in a game but not here

Browser support and permissions differ from native games. Try a current browser and confirm that no extension or browser setting blocks gamepad access.

Common questions

Does this work with PlayStation, Xbox or Nintendo controllers?

It can work with controllers that the operating system and browser expose through the Gamepad API. The labels and available controls can differ by model.

Can it calibrate my controller?

No. It displays browser-reported input only and does not modify controller settings.

Can it test controller vibration?

No. This page does not test rumble or other haptic features.

Why do I need to press a button first?

Many browsers reveal a connected controller only after an interaction, which helps prevent passive device detection.
