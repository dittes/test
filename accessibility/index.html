TEST INSTITUTE / accessibility

A test you can use.

Clear controls and useful explanations should be available however you navigate.

Keyboard navigation

Use Tab to move between links and controls. A visible outline shows focus. Every page includes a skip link to its main content. For the keyboard instrument, activate the test area first; Escape stops capture and Tab remains available to leave it.

Motion and color

Decorative transitions respect your device’s reduced-motion preference. Status messages use words, not color alone. Screen inspection uses static patterns, without flashing sequences.

Audio and camera controls

No audio plays automatically and no device access is requested on page load. Start, Stop, and Cancel controls are labeled. Browser settings and device support may limit which tools are available.

Limits of the tests

A visual screen inspection needs sight, and an audio-channel confirmation needs hearing. The explanations remain available to read, but those tasks do not have an equivalent automatic verdict. The camera test displays a preview and browser settings without making a judgment about visual quality.

Readable content

Pages reflow on small screens and at larger text sizes. Instructions and methods are ordinary HTML and stay readable even when a browser feature or the interactive script is unavailable.
